# Changelog

## 0.1.0 — Unreleased

Initial Windows x64 release candidate.

- Quiet Markdown source editing with CodeMirror 6 and local iA Writer Mono fonts.
- Warm ivory/sage light theme, OS-following dark theme, and fullscreen zen mode.
- Locally protected unnamed drafts and explicit save-to-file flow.
- Debounced autosave, external-file change detection, conflict handling, and recovery backups.
- Independent document windows, Explorer/command-line opening, file drops, and recent files.
- Literal search, deliberate web-link opening, and H1/H2 chapter navigation.
- Filled-circle app icon and per-user Windows installer with Markdown file associations.
- MIT license and private vulnerability reporting.

### Known limitations

- German interface; Windows x64 is the initial verified target.
- Unsigned installer and no automatic updates.
- UTF-8 files only; no rendered preview or large-file tuning.
- Recovery data is local and unencrypted; autosave is not an independent backup system.
- Public release downloads are not available yet.
